## DrillPod 1.8 — first public release

Unofficial Android launcher dedicated to **Motherload** (XGen Studios, 2004): play **your own copy** of the game with a gamepad, touch controls and on two screens. Every feature is tailored to Motherload's screens, shops and save system — DrillPod is not a general-purpose Flash player. Designed for the **AYN Thor**, works on Android 7.0+ phones and tablets.

> ⚠️ **No game files included.** On first launch, choose **Download the game** (Motherload from XGen Studios' official website) or **Import a file** (`8khsgfbehb.swf`). The file is verified by MD5 (`42469867aa46129edbab37894c344cb4`), then prepared on the device.

### Installation
1. Download **`DrillPod.apk`** below.
2. Open it on Android and allow installs from unknown sources if asked.
3. Start DrillPod → **Download the game** or **Import a file** → **Play**.

### What's in this release
**Gamepad**
- Every action can be remapped (driving, menus, anywhere), with automatic swapping on conflicts.
- In every game menu the cursor lands on the most useful button (*Fill Tank*, *OK*, *Sell All*, *Total Repair*…) and jumps from button to button; **B = back / close**.
- Stick read by angle (fewer accidental direction changes), adjustable sensitivity.

**Touch**
- Virtual gamepad modelled on the AYN Thor (sticks, d-pad, A/B/X/Y, shoulders, Start/Select) that works exactly like the real one, cursor included.
- Drag-and-drop layout editor, size, opacity, labels, vibration.

**Two screens**
- Live dashboard on the bottom screen: cash, depth, fuel, hull, cargo bay (%), cargo with estimated value, items, equipment, alerts.

**Display**
- Stretched 16:9, original 4:3 and wide modes; rendering at the screen's full resolution.
- Optional **high-quality mode**: 1.5× supersampling, best quality, smoothed textures.

**Saves**
- Local save and load (the old online server is gone), with automatic login: one press of A is enough.

**Launcher**
- English / French, layout adapted to every screen size, settings, licences and credits.

### Notes
- The APK is not distributed through the Play Store: Play Protect may show a warning.
- Tested in a browser at the resolutions of both AYN Thor screens; feedback welcome in *Issues*.
- This APK is built and signed automatically by GitHub Actions from the tagged source code.
- Unofficial fan project, not affiliated with or endorsed by XGen Studios. Thanks to **XGen Studios**, creators of Motherload (2004), and to the **Ruffle** team.
