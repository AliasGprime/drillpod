## DrillPod 1.9 — in-app updates

### New: automatic updates
- When the launcher opens, DrillPod checks this project's GitHub Releases (once per start) and offers the new version if there is one: **Update**, **Later** or **Skip this version**.
- The APK is downloaded, its **SHA-256 is checked** against the fingerprint published in the release notes, then handed to **Android's own installer**, which asks you to confirm. Android also refuses any update not signed with the same key as the installed app.
- The first time, Android asks you to allow DrillPod to install apps; the launcher opens the right settings screen and resumes the installation when you come back.
- New settings in **Settings → Updates**: *Check at startup* (on/off) and *Check for updates* (manual check, shows the installed version).

### Fixes
- Second screen: the waiting message no longer runs into the "DrillPod" title.
- Gamepad play: the faint touch-controls button moved to the top-right corner so it no longer covers the game's logo.

### Upgrading from 1.8
1.8 has no updater yet: install this APK over it once (same signing key, your saves and settings are kept). Later versions will be offered automatically.
